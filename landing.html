System Architecture

From physical sensors to your web browser in milliseconds.

  1. Sensory Input: The HL-03 and KY-037 detect physical changes in the environment.
  2. Microcontroller: Raspberry Pi processes digital signals and manages GPIO states.
  3. Flask Backend: Python serves the data via JSON API endpoints.
  4. Frontend: The browser renders the UI and Canvas charts in real-time.

Hardware Wiring Guide

Connect the components securely to the Raspberry Pi GPIO.

ComponentPi PinDescription
Sound Sensor (KY-037) GPIO 17 Digital Output (DO) connected to Pin 11.
Raindrop Sensor (HL-03) GPIO 27 Digital Output (DO) connected to Pin 13.
Active Buzzer GPIO 23 Positive to Pin 16, Negative to Ground (Pin 20).
